Part I — Problems found

Code review: mono-radar and multi-radar coverage

The coverage maths is sound: mono-radar geometry and the multi-radar overlap breakdown both matched independent references. Nearly every bug sits in the layers around it — caching, file output and option handling — and several of them silently produce wrong maps. The repo has no tests, and about 15% of the code is dead.

Everything ran on a copy of the repo at commit ba079d8, using the bundled spain.tsk radar data, PHP 8.3 and PHPStan 2.1.

Mono-radar coverage

The geometry is correct, but PSR radars always come out empty and the cache ignores both the cone flag and changes to the screening file. Code: inc.calculos.php, plus calculosFL in main.php.

What holds up

  • Positions: vertices sit within ~20 m of the exact spherical position. The error grows to ~80 m at 250 NM in Spain and ~300 m at 60°N.
  • Area above the radar: within 0.0–0.5% of the shadow-aware reference at every flight level tested (paracuellos1, valdespina, erillas, alcolea).
  • Speed: about 1 s per radar per flight level below the radar, well under that above it.

Multi-radar coverage

The breakdown is exactly right on a cold cache, but the polygon disk cache hands back results from a different radar set, so a warm cache produces wrong maps. Code: inc.multiCalculos.php.

What holds up

  • Coverage levels: every one of 20,000 sampled points landed in the right "exactly k radars" layer, for both a 3-radar and a 9-radar run.
  • Method: each level is the intersection of a radar group minus the union of all other radars, which is correct.

Suggested priorities

Fix the two bugs that crash or blank results first, then the caches that silently serve wrong maps.

    • Mono cache: add the cone flag, the max range and the .scr file date.
    • Polygon cache: add the full radar set, the operation type and the date of the single-radar results it was built from.
    • Make -f clear the polygon cache too.

Mathematics review: errors, precision and speed

No error in the core geometry changes the maps by much. The biggest correctness problem is the polygon-union step, and the biggest wins are speed. All tests ran on 9 radars × FL1–400.

Checked and correct: the formula for the maximum coverage angle (law of cosines on the 4/3-Earth model), the conversion of central angle to ground distance, and the "wall" extension beyond the last screening point. That extension assumes the last screening point is the highest-elevation one, and it is on 99.9% of azimuths.

How to apply and verify

Apply the changes in order on a branch; line numbers refer to the files at ba079d8, before any edit.

  1. Changes 1–4 are small, independent edits. Each can be applied and checked on its own.
  2. Change 5 edits the top of inc.calculos.php. Apply it after Change 6 if you go by line numbers, or match the text instead.
  3. Change 6 replaces one contiguous block of inc.calculos.php: lines 156–784, from the /** above * CASO A down to the closing } of calcula_vertices_interseccion(), just before the Ramer–Douglas–Peucker comment. Parts A–E, pasted in that order, are the new block.
  4. Changes 7 and 8 are in inc.multiCalculos.php and depend only on the existing MR alias.
  5. Delete the caches after applying: rm -rf cache/. The single-radar cache is only invalidated when an .rdb changes, so old JSON polygons would otherwise be reused.
  6. Check: php -l on the four files, then vendor/bin/phpstan analyse. Expect only the two findings that already exist (duplicate version key, generateMatlabFiles), plus "always false" notes in perfil_cartesiano while BERTA_PERFIL_ESCALONADO is false.

Two flags stay off by default, because both depend on how PREDICT defines its data:

  • BERTA_PERFIL_ESCALONADO (E4): the visibility floor follows the highest line of sight so far. Effect: +0.2–3.8% coverage near radar height, about 0 from FL100 up. Turn on once you confirm the screening points are terrain/horizon points rather than an already-computed shadow line.
  • BERTA_ELIPSOIDE_WGS84 (P2): positions on WGS84 via Vincenty instead of a 6,371 km sphere. Effect: moves vertices 120–235 m at 50 NM and about 1.1 km at 250 NM; costs about 4 ms per level. Turn on once a PREDICT coverage export confirms its distances are true ground distances.

Change 6 — inc.calculos.php: replacement block, part A

Change 6 replaces lines 156–784 of inc.calculos.php with parts A–E pasted in order. It removes create_matriz_obstaculos(), create_matriz_intersecciones(), create_poligonos_cobertura() and calcula_vertices_interseccion(); nothing else calls them. calculaCoordenadasCono(), polarToLatLon() and everything from the Ramer–Douglas–Peucker comment down stay as they are.

What the new block does:

  • Terrain profile once per radar (part B). It no longer depends on the flight level; each level only truncates it and adds the wall (S2).
  • Robust crossings (part C). Each point is classified inside/outside the flight-level circle once, so the crossing count always has the right parity without W += 0.01 or an epsilon (E6). Segments that can't cut the circle are skipped (S2).
  • Outline from intervals (part D). Below the radar, the outline is traced straight from each azimuth's covered distance intervals. There is no polygon union, no 20 m overlap and no rounding (E3, S1).
  • Exact positions (part E): an exact spherical formula, with optional WGS84 (P1, P2).

Part A holds the three functions calculosFL() already calls, with the same signatures. Above the radar, the star polygon stays as today whenever every azimuth has exactly one crossing (all 3,600 radar-level cases tested). Otherwise it switches to the interval construction, which fixes the latent ridge case. create_muro() now returns a list of points, so the capped wall point stays on the range line (E7).

php
/**
 * CASO A
 * Cobertura cuando el nivel de vuelo está por encima del radar.
 * Si todos los acimuts tienen un único cruce, se devuelve un polígono en estrella que une el alcance de cada
 * acimut (interpolación lineal entre acimuts). Si algún acimut tiene varios cruces (el haz vuelve a quedar por
 * encima del nivel tras una sierra), se construye la cobertura por intervalos, igual que en el CASO B.
 *
 * @param array $radar (ENTRADA)
 * @param float $flm nivel de vuelo en metros (ENTRADA)
 * @return array lista de anillos [[lat, lon], ...] (SALIDA)
 */
function calculosFLencimaRadar2(array $radar, float $flm): array
{
    $cruces = calcula_cruces($radar, $flm);

    foreach ($cruces as $lista) {
        if (1 != count($lista)) {
            logger(" D> Acimuts con varios cruces por encima del radar, se usa la construcción por intervalos");
            return poligonos_desde_intervalos($radar, intervalos_desde_cruces($cruces, true));
        }
    }

    $azimuth_step = 360.0 / count($cruces);
    $anillo = array();
    foreach (array_values($cruces) as $j => $lista) {
        $anillo[] = destino($radar['lat_rad'], $radar['lon_rad'], $lista[0] * BERTA_MILLA_NAUTICA_EN_METROS, deg2rad($j * $azimuth_step));
    }
    return [$anillo];
}

/**
 * Muro final de cobertura: intersección de la recta radar -> último obstáculo con la recta de alcance máximo
 * (y = m·x), más el punto de la recta de alcance a BERTA_MAX_WALL_HEIGHT si la intersección queda por debajo.
 *
 * @return array lista de puntos [x, y] a añadir tras el último obstáculo (vacía si no hay muro)
 */
function create_muro(array &$radar, float $xa, float $ya, float $xb, float $yb, float $m): array
{
    /* Intersección segmento - línea
     *   x = xa + t*(xb-xa), y = ya + t*(yb-ya)
     *   y = m*x
     *   t = (m*xa - ya) / ((yb-ya) - m*(xb-xa))
     */
    $dx = $xb - $xa;
    $dy = $yb - $ya;
    $den = $dy - $m * $dx;
    if (0.0 == $den) {
        return array();
    }
    $t = ($m * $xa - $ya) / $den;
    if ($t < 1) { // la recta de alcance queda antes del último obstáculo
        return array();
    }
    $xi = $xa + $t * $dx;
    $yi = $ya + $t * $dy;
    $radioTope = BERTA_MAX_WALL_HEIGHT + $radar['screening']['radioTerrestreAumentado'];
    if (hypot($xi, $yi) >= $radioTope) {
        // la intersección ya está por encima del tope del muro: basta con ella (antes se movía fuera de la recta)
        return array([$xi, $yi]);
    }
    $alpha_m = atan($m);
    return array([$xi, $yi], [$radioTope * cos($alpha_m), $radioTope * sin($alpha_m)]);
}

/*
 * CASO B
 * Cobertura cuando el nivel de vuelo está por debajo del radar.
 *
 * @param array $radar (ENTRADA)
 * @param float $flm nivel de vuelo en metros (ENTRADA)
 * @return array lista de anillos [[lat, lon], ...]; vacía si no hay cobertura
 */
function calculosFLdebajoRadar2(array &$radar, float $flm): array
{
    $cruces = calcula_cruces($radar, $flm);
    return poligonos_desde_intervalos($radar, intervalos_desde_cruces($cruces, false));
}

Change 6, part B — perfil_cartesiano

Paste directly after part A. This builds each azimuth's terrain profile in the Earth-centred x/y plane once per radar and caches it in a static variable keyed by radar name. Before, create_matriz_obstaculos() recomputed every sine and cosine on every flight level. It also stores, per segment, the smallest x²+y² along it (min2), which lets part C skip segments that can't reach the flight-level circle.

With BERTA_PERFIL_ESCALONADO = false, the points are exactly those the old code used (radar first, then every obstacle), so the crossings are identical. With it true, points hidden behind the current horizon are dropped, and before each new horizon a corner point is added on the previous line of sight at that point's central angle (E4).

php
/**
 * Perfil de cada acimut en coordenadas cartesianas respecto al centro de la Tierra aumentada, independiente
 * del nivel de vuelo. Se calcula una vez por radar y se guarda en una caché estática.
 * Para cada acimut: x, y, ang (ángulo central), r2 (x²+y²) por punto y min2 (mínimo de x²+y² sobre el
 * segmento k -> k+1), que permite descartar segmentos que no pueden cortar la circunferencia del nivel.
 *
 * Con BERTA_PERFIL_ESCALONADO el suelo de visibilidad sigue la línea de visión más alta hasta cada punto:
 * los puntos ocultos se descartan y, antes de cada nuevo horizonte, se añade la esquina sobre la línea de
 * visión anterior.
 */
function perfil_cartesiano(array &$radar): array
{
    static $cache = array();
    $clave = $radar['radar'] . '|' . ($radar['screening_file'] ?? '') . '|' . (BERTA_PERFIL_ESCALONADO ? 1 : 0);
    if (isset($cache[$clave])) {
        return $cache[$clave];
    }

    $Rk = $radar['screening']['radioTerrestreAumentado'];
    $ya = $Rk + $radar['screening']['towerHeight'] + $radar['screening']['terrainHeight'];
    $perfil = array();
    foreach ($radar['screening']['listaAzimuths'] as $azimut => $listaObstaculos) {
        $x = [0.0]; $y = [$ya]; $ang = [0.0]; // el radar es el primer punto
        $hx = null; $hy = null; $emax = -INF;
        foreach ($listaObstaculos as $i => $obstaculo) {
            if (0 == $i) {
                continue; // obstáculo 0 = el propio radar, insertado al cargar el screening
            }
            $r = $Rk + $obstaculo['altura'];
            $a = $obstaculo['angulo'];
            $px = $r * sin($a);
            $py = $r * cos($a);
            if (BERTA_PERFIL_ESCALONADO) {
                $e = atan2($py - $ya, $px); // ángulo de elevación visto desde el radar
                if ($e <= $emax) {
                    continue; // oculto tras el horizonte actual
                }
                if (null !== $hx) {
                    // esquina: línea de visión del horizonte actual evaluada en el ángulo central de este punto
                    $den = $hx * cos($a) - ($hy - $ya) * sin($a);
                    if (0.0 != $den) {
                        $s = $ya * sin($a) / $den;
                        $x[] = $s * $hx; $y[] = $ya + $s * ($hy - $ya); $ang[] = $a;
                    }
                }
                $hx = $px; $hy = $py; $emax = $e;
            }
            $x[] = $px; $y[] = $py; $ang[] = $a;
        }
        $n = count($x);
        $r2 = array(); $min2 = array();
        for ($k = 0; $k < $n; $k++) {
            $r2[$k] = $x[$k] * $x[$k] + $y[$k] * $y[$k];
        }
        for ($k = 0; $k < $n - 1; $k++) {
            $dx = $x[$k + 1] - $x[$k]; $dy = $y[$k + 1] - $y[$k];
            $A = $dx * $dx + $dy * $dy;
            $t = ($A > 0) ? -($x[$k] * $dx + $y[$k] * $dy) / $A : 0.0;
            $min2[$k] = ($t > 0 && $t < 1)
                ? (($x[$k] + $t * $dx) ** 2 + ($y[$k] + $t * $dy) ** 2)
                : min($r2[$k], $r2[$k + 1]);
        }
        $perfil[$azimut] = array('x' => $x, 'y' => $y, 'ang' => $ang, 'r2' => $r2, 'min2' => $min2);
    }
    return $cache[$clave] = $perfil;
}

The corner point: the line of sight from the radar (0, ya) through the current horizon point (hx, hy) is (s·hx, ya + s·(hy−ya)). The radial line at central angle a satisfies x·cos(a) − y·sin(a) = 0. Solving gives s = ya·sin(a) / (hx·cos(a) − (hy−ya)·sin(a)).

Change 6, part C — calcula_cruces and cruces_segmento

Paste after part B. calcula_cruces() replaces create_matriz_obstaculos() + create_matriz_intersecciones(). It returns, for each azimuth, the distances (NM) where the profile crosses the flight-level circle, in order from the radar. That's the same format as the old $intersec.

Three differences from the old code:

  1. Truncation at the maximum range angle uses a binary search on the central angles. They are increasing in every bundled file (0 out-of-order steps).
  2. Segment rejection: if both ends are inside the circle, or both are outside and the segment's closest approach (min2) is also outside, the segment can't cross and is skipped.
  3. Classification: each point's sign f = x²+y²−W² is computed once and shared by the two segments that meet there. My first attempt computed f separately per segment (C and A+B+C); a terrain point exactly on the FL25 circle then came out "inside" for one segment and "outside" for the next, losing a crossing. With one sign per point the count always has the right parity: odd above the radar, even below.

In cruces_segmento():

  • One end inside, one outside: exactly one root. It uses the numerically stable form q = −½(B + sign(B)·√D) and keeps the root that falls in [0, 1].
  • Both ends outside: two roots only if the segment's closest point is inside the circle. Straight rays in the 4/3-Earth model can dip below a flight level and rise again.
  • Both ends inside: no crossing. A circle is convex, so a segment between two inside points stays inside.

The distance is Rk·atan2(x, y)/1852, the same as the old π/2 − atan2(y, x).

php
/**
 * Cruces entre la circunferencia del nivel de vuelo y el perfil (más el muro final) de cada acimut.
 * Sustituye a create_matriz_obstaculos() + create_matriz_intersecciones().
 * Cada punto se clasifica una sola vez como dentro (r² < W²) o fuera, así que la paridad de los cruces
 * es siempre correcta sin sumar 10 cm a W ni usar épsilon.
 *
 * @return array [acimut => lista de distancias en NM, en orden desde el radar]
 */
function calcula_cruces(array &$radar, float $flm): array
{
    $perfil = perfil_cartesiano($radar);
    $Rk = $radar['screening']['radioTerrestreAumentado'];
    $W = $Rk + $flm; // radio de la circunferencia del nivel de vuelo
    $W2 = $W * $W;
    $alpha_max = calculaAnguloMaximaCobertura($radar, $flm);
    $m = tan(M_PI_2 - $alpha_max); // recta de alcance máximo

    $cruces = array();
    foreach ($perfil as $azimut => $p) {
        // número de puntos con ángulo central <= alpha_max (los ángulos son crecientes)
        $lo = 0; $hi = count($p['ang']);
        while ($lo < $hi) {
            $mid = ($lo + $hi) >> 1;
            if ($p['ang'][$mid] <= $alpha_max) $lo = $mid + 1; else $hi = $mid;
        }
        $n = $lo;
        $lista = array();
        for ($k = 0; $k < $n - 1; $k++) {
            $dentro1 = $p['r2'][$k] < $W2;
            $dentro2 = $p['r2'][$k + 1] < $W2;
            if ($dentro1 === $dentro2 && ($dentro1 || $p['min2'][$k] >= $W2)) {
                continue; // el segmento no puede cortar la circunferencia
            }
            cruces_segmento($p['x'][$k], $p['y'][$k], $p['x'][$k + 1], $p['y'][$k + 1],
                $p['r2'][$k] - $W2, $p['r2'][$k + 1] - $W2, $Rk, $lista);
        }
        // muro final, si el último punto conservado no es ya un muro
        if ($n >= 2) {
            $xb = $p['x'][$n - 1]; $yb = $p['y'][$n - 1];
            if (sqrt($p['r2'][$n - 1]) - $Rk <= 30000) {
                $fprev = $p['r2'][$n - 1] - $W2;
                foreach (create_muro($radar, 0.0, $p['y'][0], $xb, $yb, $m) as [$xm, $ym]) {
                    $fm = $xm * $xm + $ym * $ym - $W2;
                    cruces_segmento($xb, $yb, $xm, $ym, $fprev, $fm, $Rk, $lista);
                    $xb = $xm; $yb = $ym; $fprev = $fm;
                }
            }
        }
        $cruces[$azimut] = $lista;
    }
    return $cruces;
}

/**
 * Cruces de un segmento con la circunferencia de radio W. $f1 y $f2 son x²+y²-W² en los extremos,
 * calculados una sola vez por punto para que dos segmentos contiguos clasifiquen igual el punto común.
 * Añade a $lista la distancia (NM, sobre la Tierra aumentada) de cada cruce.
 */
function cruces_segmento(float $x1, float $y1, float $x2, float $y2, float $f1, float $f2, float $Rk, array &$lista): void
{
    $dx = $x2 - $x1;
    $dy = $y2 - $y1;
    $A = $dx * $dx + $dy * $dy;
    if (0.0 == $A) {
        return;
    }
    $B = 2 * ($x1 * $dx + $y1 * $dy);
    $C = $f1;
    $ts = array();
    if (($f1 < 0) !== ($f2 < 0)) {
        // un extremo dentro y otro fuera: exactamente un cruce en [0,1]
        $s = sqrt(max(0.0, $B * $B - 4 * $A * $C));
        $q = -0.5 * ($B + ($B >= 0 ? $s : -$s)); // fórmula estable
        $t1 = $q / $A;
        $t2 = (0.0 != $q) ? $C / $q : $t1;
        $e1 = ($t1 < 0) ? -$t1 : (($t1 > 1) ? $t1 - 1 : 0.0);
        $e2 = ($t2 < 0) ? -$t2 : (($t2 > 1) ? $t2 - 1 : 0.0);
        $ts[] = max(0.0, min(1.0, ($e1 <= $e2) ? $t1 : $t2));
    } elseif ($f1 >= 0) {
        // los dos extremos fuera: dos cruces si el segmento entra en el círculo
        $tv = -$B / (2 * $A);
        if ($tv > 0 && $tv < 1 && ($C - $B * $B / (4 * $A)) < 0) {
            $s = sqrt($B * $B - 4 * $A * $C);
            $ts[] = (-$B - $s) / (2 * $A);
            $ts[] = (-$B + $s) / (2 * $A);
        }
    } // los dos dentro: un segmento dentro de un círculo no puede salir de él
    foreach ($ts as $t) {
        $xi = $x1 + $t * $dx;
        $yi = $y1 + $t * $dy;
        $lista[] = $Rk * atan2($xi, $yi) / BERTA_MILLA_NAUTICA_EN_METROS; // ángulo central desde el eje y
    }
}

Change 6, part D — intervals and outline tracing

Paste after part C. These two functions replace create_poligonos_cobertura(). The old code built one annular sector per covered interval, widened each by 20 m sideways so neighbours overlapped, and merged hundreds of them with MR\Algorithm::unionMany. That took 97% of the time below the radar. In testing the library also returned an empty result for valid input once, and threw PolyBoolException on barajas.

intervalos_desde_cruces() pairs the crossings into covered intervals. Below the radar the profile starts above the flight level, so the pairs are (c0,c1), (c2,c3)… Above the radar it starts below, so the intervals are [0,c0], (c1,c2)…

poligonos_desde_intervalos() traces the outline directly, treating azimuth bin j as spanning j·step ± step/2:

  1. Merge touching intervals inside each bin.
  2. Create directed edges with the covered region on the left. Each interval gets a lower arc (+u) and an upper arc (−u). Each bin boundary gets the radial stretches covered on one side only: +v where only the left bin covers, −v where only the right bin covers.
  3. Chain the edges into rings. Where two rings touch at one vertex, prefer a left turn, so they stay separate rings.
  4. Convert vertices to lat/lon with destino(). Radial sides longer than BERTA_SUBDIVISION_RADIAL_NM (10 NM) are subdivided, because a great circle isn't straight in lat/lon.

The output has the same shape as getArray(): a list of rings, first point not repeated. Nesting (holes) is still sorted out by KML_normalizePolygonsForKML(), unchanged.

php
/**
 * Convierte los cruces de cada acimut en intervalos cubiertos [inicio, fin] en NM.
 * Por debajo del radar el perfil empieza por encima del nivel: (c0,c1), (c2,c3)...
 * Por encima del radar empieza por debajo: [0,c0], (c1,c2)...
 */
function intervalos_desde_cruces(array $cruces, bool $encima): array
{
    $intervalos = array();
    foreach (array_values($cruces) as $j => $lista) {
        if ($encima) {
            array_unshift($lista, 0.0);
        }
        $iv = array();
        for ($i = 0; $i + 1 < count($lista); $i += 2) {
            if ($lista[$i + 1] > $lista[$i]) {
                $iv[] = [$lista[$i], $lista[$i + 1]];
            }
        }
        $intervalos[$j] = $iv;
    }
    return $intervalos;
}

/**
 * Contorno de la cobertura a partir de los intervalos de cada acimut, sin unión de polígonos.
 * El acimut j cubre [j·paso - paso/2, j·paso + paso/2]. Se generan las aristas del borde (arcos en cada
 * intervalo y tramos radiales donde sólo un acimut vecino tiene cobertura) y se encadenan en anillos.
 * Sustituye a create_poligonos_cobertura(): sin solape de 20 m, sin redondeo de ángulos y sin Martinez-Rueda.
 *
 * @param array $intervalos [j => [[inicio_nm, fin_nm], ...]]
 * @return array lista de anillos [[lat, lon], ...] (sin repetir el primer punto), mismo formato que getArray()
 */
function poligonos_desde_intervalos(array $radar, array $intervalos): array
{
    $N = count($intervalos);
    if (0 == $N) {
        return array();
    }
    $paso = 360.0 / $N;

    // ordenar y fusionar intervalos que se tocan dentro de cada acimut
    $bins = array();
    for ($j = 0; $j < $N; $j++) {
        $iv = $intervalos[$j] ?? array();
        usort($iv, fn($a, $b) => $a[0] <=> $b[0]);
        $fusion = array();
        foreach ($iv as [$s, $e]) {
            if ($e <= $s) continue;
            $u = count($fusion) - 1;
            if ($u >= 0 && $s <= $fusion[$u][1]) $fusion[$u][1] = max($fusion[$u][1], $e);
            else $fusion[] = [$s, $e];
        }
        $bins[$j] = $fusion;
    }

    // aristas dirigidas en el plano (u = índice de frontera de acimut, v = distancia), región a la izquierda
    // dirección: 0 = +u, 1 = +v, 2 = -u, 3 = -v
    $salidas = array();
    $puntos = array();
    $arista = function (int $k1, float $r1, int $k2, float $r2, int $dir) use (&$salidas, &$puntos, $N): void {
        $k1 %= $N; $k2 %= $N;
        $a = $k1 . '|' . $r1; $b = $k2 . '|' . $r2;
        $puntos[$a] = [$k1, $r1]; $puntos[$b] = [$k2, $r2];
        $salidas[$a][] = [$b, $dir];
    };
    for ($j = 0; $j < $N; $j++) {
        foreach ($bins[$j] as [$s, $e]) {
            $arista($j, $s, $j + 1, $s, 0);   // arco inferior
            $arista($j + 1, $e, $j, $e, 2);   // arco superior
        }
    }
    $cubre = function (array $set, float $x): bool {
        foreach ($set as [$s, $e]) if ($x > $s && $x < $e) return true;
        return false;
    };
    for ($k = 0; $k < $N; $k++) { // frontera k, entre el acimut k-1 y el k
        $L = $bins[($k - 1 + $N) % $N];
        $R = $bins[$k];
        $cortes = array();
        foreach ([$L, $R] as $set) foreach ($set as [$s, $e]) { $cortes[(string) $s] = $s; $cortes[(string) $e] = $e; }
        $cortes = array_values($cortes);
        sort($cortes);
        for ($i = 0; $i < count($cortes) - 1; $i++) {
            $a = $cortes[$i]; $b = $cortes[$i + 1]; $medio = 0.5 * ($a + $b);
            $l = $cubre($L, $medio); $r = $cubre($R, $medio);
            if ($l && !$r) $arista($k, $a, $k, $b, 1);      // región a la izquierda de la frontera
            elseif ($r && !$l) $arista($k, $b, $k, $a, 3);  // región a la derecha de la frontera
        }
    }

    // encadenar aristas en anillos; en un vértice con varias salidas se prefiere girar a la izquierda
    $preferencia = array(0 => [1, 0, 3], 1 => [2, 1, 0], 2 => [3, 2, 1], 3 => [0, 3, 2]);
    $anillos = array();
    foreach (array_keys($salidas) as $inicio) {
        while (!empty($salidas[$inicio])) {
            $anillo = array($inicio);
            [$actual, $dir] = array_pop($salidas[$inicio]);
            while ($actual !== $inicio) {
                $anillo[] = $actual;
                $opciones = $salidas[$actual] ?? array();
                if (empty($opciones)) {
                    logger(" E> Contorno abierto en poligonos_desde_intervalos (vértice {$actual})");
                    break;
                }
                $elegida = array_key_first($opciones);
                foreach ($preferencia[$dir] as $quiero) {
                    foreach ($opciones as $i => $o) {
                        if ($o[1] === $quiero) { $elegida = $i; break 2; }
                    }
                }
                [$siguiente, $dir] = $opciones[$elegida];
                unset($salidas[$actual][$elegida]);
                $actual = $siguiente;
            }
            $anillos[] = $anillo;
        }
    }

    // a lat/lon, subdividiendo los lados radiales largos
    $latlon = array();
    $aLatLon = function (int $k, float $r) use ($radar, $paso, &$latlon): array {
        $clave = $k . '|' . $r;
        if (!isset($latlon[$clave])) {
            $latlon[$clave] = ($r <= 0.0)
                ? [rad2deg($radar['lat_rad']), rad2deg($radar['lon_rad'])]
                : destino($radar['lat_rad'], $radar['lon_rad'], $r * BERTA_MILLA_NAUTICA_EN_METROS, deg2rad($k * $paso - $paso / 2));
        }
        return $latlon[$clave];
    };
    $resultado = array();
    foreach ($anillos as $anillo) {
        $poly = array();
        $n = count($anillo);
        for ($i = 0; $i < $n; $i++) {
            [$k1, $r1] = $puntos[$anillo[$i]];
            [$k2, $r2] = $puntos[$anillo[($i + 1) % $n]];
            $p = $aLatLon($k1, $r1);
            if (empty($poly) || $poly[count($poly) - 1] != $p) $poly[] = $p;
            if ($k1 === $k2 && abs($r2 - $r1) > BERTA_SUBDIVISION_RADIAL_NM) {
                $ns = (int) ceil(abs($r2 - $r1) / BERTA_SUBDIVISION_RADIAL_NM);
                for ($s = 1; $s < $ns; $s++) {
                    $poly[] = $aLatLon($k1, $r1 + ($r2 - $r1) * $s / $ns);
                }
            }
        }
        if (count($poly) > 1 && $poly[0] == $poly[count($poly) - 1]) array_pop($poly);
        if (count($poly) >= 3) $resultado[] = $poly;
    }
    return $resultado;
}

Change 6, part E — destino and destinoVincenty

Paste after part D. This is the last piece of the Change 6 block, ending just before the Ramer–Douglas–Peucker comment. destino() replaces calcula_vertices_interseccion().

The old function was exact for latitude, but its longitude step was an approximation: 80 m off at 250 NM in Spain and 300 m at 60°N. It also shifted every vertex 20 m sideways for the union overlap. The exact spherical formula is shorter and 2.7× faster per vertex (0.31 µs against 0.86 µs).

With BERTA_ELIPSOIDE_WGS84 = true it uses Vincenty's direct solution on WGS84 (P2), at about 1.5 µs per vertex, roughly 4 ms per flight level. The implementation was checked against known values: 111,319.49 m east along the equator gives 1.0000000°, and 110,574.39 m north from the equator gives 1.0000000°. A single local Earth radius (Euler) is not enough: it still errs by about 180 m at 50 NM on diagonal azimuths.

php
/**
 * Problema directo: punto a $dist_m metros del radar con rumbo $az_rad.
 * Esfera de radio BERTA_RADIO_TERRESTRE (fórmula exacta) o, con BERTA_ELIPSOIDE_WGS84, geodésica de Vincenty.
 * Sustituye a calcula_vertices_interseccion(), cuya fórmula de longitud era aproximada.
 *
 * @return array [lat, lon] en grados
 */
function destino(float $lat_rad, float $lon_rad, float $dist_m, float $az_rad): array
{
    if (BERTA_ELIPSOIDE_WGS84) {
        return destinoVincenty($lat_rad, $lon_rad, $dist_m, $az_rad);
    }
    $d = $dist_m / BERTA_RADIO_TERRESTRE;
    $sinLat = sin($lat_rad); $cosLat = cos($lat_rad);
    $cosD = cos($d); $sinD = sin($d);
    $sinLat2 = $sinLat * $cosD + $cosLat * $sinD * cos($az_rad);
    $lat2 = asin(max(-1.0, min(1.0, $sinLat2)));
    $lon2 = $lon_rad + atan2(sin($az_rad) * $sinD * $cosLat, $cosD - $sinLat * $sinLat2);
    return [rad2deg($lat2), rad2deg($lon2)];
}

/**
 * Problema directo de Vincenty sobre el elipsoide WGS84.
 * @return array [lat, lon] en grados
 */
function destinoVincenty(float $lat_rad, float $lon_rad, float $dist_m, float $az_rad): array
{
    $a = 6378137.0; $f = 1 / 298.257223563; $b = $a * (1 - $f);
    $U1 = atan((1 - $f) * tan($lat_rad));
    $sigma1 = atan2(tan($U1), cos($az_rad));
    $sinAlpha = cos($U1) * sin($az_rad);
    $cos2Alpha = 1 - $sinAlpha * $sinAlpha;
    $u2 = $cos2Alpha * ($a * $a - $b * $b) / ($b * $b);
    $A = 1 + $u2 / 16384 * (4096 + $u2 * (-768 + $u2 * (320 - 175 * $u2)));
    $B = $u2 / 1024 * (256 + $u2 * (-128 + $u2 * (74 - 47 * $u2)));
    $sigma = $dist_m / ($b * $A);
    $cos2SigmaM = cos(2 * $sigma1 + $sigma);
    for ($i = 0; $i < 100; $i++) {
        $cos2SigmaM = cos(2 * $sigma1 + $sigma);
        $sinSigma = sin($sigma);
        $deltaSigma = $B * $sinSigma * ($cos2SigmaM + $B / 4 * (cos($sigma) * (-1 + 2 * $cos2SigmaM ** 2)
            - $B / 6 * $cos2SigmaM * (-3 + 4 * $sinSigma ** 2) * (-3 + 4 * $cos2SigmaM ** 2)));
        $anterior = $sigma;
        $sigma = $dist_m / ($b * $A) + $deltaSigma;
        if (abs($sigma - $anterior) < 1e-12) break;
    }
    $sinSigma = sin($sigma); $cosSigma = cos($sigma);
    $cos2SigmaM = cos(2 * $sigma1 + $sigma);
    $tmp = sin($U1) * $sinSigma - cos($U1) * $cosSigma * cos($az_rad);
    $lat2 = atan2(sin($U1) * $cosSigma + cos($U1) * $sinSigma * cos($az_rad), (1 - $f) * sqrt($sinAlpha * $sinAlpha + $tmp * $tmp));
    $lambda = atan2($sinSigma * sin($az_rad), cos($U1) * $cosSigma - sin($U1) * $sinSigma * cos($az_rad));
    $C = $f / 16 * $cos2Alpha * (4 + $f * (4 - 3 * $cos2Alpha));
    $L = $lambda - (1 - $C) * $f * $sinAlpha * ($sigma + $C * $sinSigma * ($cos2SigmaM + $C * $cosSigma * (-1 + 2 * $cos2SigmaM ** 2)));
    return [rad2deg($lat2), rad2deg($lon_rad + $L)];
}

Change 8 — inc.multiCalculos.php: multi_refinamiento

New function; append it at the end of inc.multiCalculos.php, after cache_operation().

Method. Radars are added one at a time. Adding radar S splits every existing region P into P∩S (now also covered by S) and P−S (unchanged), and adds S−(union so far) as S's own region. Empty regions are dropped, so the number of operations follows the number of overlap regions that actually exist, not the 2^N−1 groups. For 9 radars at FL150 that's 93 regions and 327 operations, against 1,323 before. If S doesn't touch P at all, the difference is skipped.

Caching. The disk cache key is the SHA-1 of the flight level, the radar names and the serialized input polygons. Any change to a single-radar coverage (new .scr, -m, -c, a fix in the maths) therefore misses the cache instead of returning stale results (X2). Files go to cache/multi/, relative to the working directory like the existing cache/polygons/.

php
/**
 * Cobertura multiradar por refinamiento incremental.
 * Al añadir el radar S, cada celda P se parte en P∩S (pasa a tener S) y P−S (se queda igual), y se añade
 * S−(unión de los anteriores). Las celdas vacías se descartan, así que el trabajo depende del número de zonas
 * de solape que existen y no de las 2^N−1 combinaciones de radares.
 * El resultado se guarda en disco con una clave que incluye el nivel de vuelo, los radares y el contenido de
 * sus polígonos, de modo que un cambio en cualquier cobertura monoradar invalida la caché.
 *
 * @param array<string, MR\Polygon> $mr_polygons polígono de cada sensor
 * @return array{celdas: array<string, MR\Polygon>, union: MR\Polygon} celdas: "a,b" => zona cubierta exactamente por a y b
 */
function multi_refinamiento(array $mr_polygons, string $flWithPad): array
{
	ksort($mr_polygons);
	$clave = sha1($flWithPad . '|' . implode(',', array_keys($mr_polygons)) . '|' . serialize($mr_polygons));
	$ruta = "cache" . DIRECTORY_SEPARATOR . "multi" . DIRECTORY_SEPARATOR . $clave[0] . $clave[1] . DIRECTORY_SEPARATOR;
	$fichero = $ruta . $clave . ".ser";
	if (is_file($fichero)) {
		$cacheado = unserialize(
			(string) file_get_contents($fichero),
			['allowed_classes' => [MR\Polygon::class, MR\Point::class]]
		);
		if (is_array($cacheado) && isset($cacheado['celdas'], $cacheado['union'])) {
			logger(" D> Multicobertura recuperada de la caché {$fichero}");
			return $cacheado;
		}
	}

	$timer = microtime(true);
	$operaciones = 0;
	$celdas = array();
	$union = null;
	foreach ($mr_polygons as $sensor => $S) {
		$nuevas = array();
		foreach ($celdas as $nombre => $P) {
			$interseccion = MR\Algorithm::intersect($P, $S); $operaciones++;
			if ($interseccion->numPoints > 0) {
				$nuevas[$nombre . ',' . $sensor] = $interseccion;
				$resta = MR\Algorithm::difference($P, $S); $operaciones++;
				if ($resta->numPoints > 0) {
					$nuevas[$nombre] = $resta;
				}
			} else {
				$nuevas[$nombre] = $P; // S no toca esta celda
			}
		}
		if (null === $union) {
			$solo = $S;
			$union = $S;
		} else {
			$solo = MR\Algorithm::difference($S, $union); $operaciones++;
			$union = MR\Algorithm::union($union, $S); $operaciones++;
		}
		if ($solo->numPoints > 0) {
			$nuevas[$sensor] = $solo;
		}
		$celdas = $nuevas;
	}
	logger(" V> Refinamiento multiradar: " . count($celdas) . " zonas, {$operaciones} operaciones, " . round(microtime(true) - $timer, 3) . "s");

	$resultado = array('celdas' => $celdas, 'union' => $union);
	crearCarpetaResultados($ruta);
	file_put_contents($fichero, serialize($resultado));
	return $resultado;
}
